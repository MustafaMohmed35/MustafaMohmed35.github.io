MUSTAFA MOHAMED — PERSONAL PORTFOLIO

FILES
- index.html       Main page and SEO metadata
- style.css        Responsive styling and animations
- script.js        Mobile menu, scroll animation, language switch
- assets/          Your profile photo and favicon
- robots.txt       Search-engine crawling guidance
- sitemap.xml      Sitemap starter file

RUN IN VS CODE
1. Extract this ZIP.
2. Open the extracted "mustafa_portfolio" folder in VS Code.
3. Open index.html in your browser, or install the "Live Server" extension,
   right-click index.html, and choose "Open with Live Server".

IMPORTANT BEFORE PUBLISHING
- Replace YOUR-DOMAIN.com in robots.txt and sitemap.xml with your real domain.
- Update the canonical URL if you add one later.
- The three project cards are clearly presented as sample practice concepts,
  not verified client projects. Replace them with your real work as you build it.
- Search engines cannot index a folder that exists only on your computer.
  Publish the site first (for example, with GitHub Pages, Netlify, or hosting),
  then add the published domain to Google Search Console and submit sitemap.xml.
- Google indexing and ranking are not guaranteed or instant.
- The educational wording "Intermediate Education" is a general English rendering
  of "مؤهل متوسط". Change it if you want a more exact certificate title.
